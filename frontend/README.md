# 🚀 Dron AI - Career & Placement Intelligence Platform

Dron AI is an intelligent platform designed for career preparation, company placement prediction, resume analysis, and GitHub intelligence.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide Icons
- **Bundler / Build Tool:** Vite
- **Styling:** Tailwind CSS & PostCSS

---

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```
Open your browser and visit the local URL shown in the terminal (usually http://localhost:5173).

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```

---

## ✨ Features

- 🎯 **Company Predictor:** AI-powered placement prediction based on your profile & skills.
- 📄 **Resume Studio:** Real-time resume score analysis and suggestions.
- 🐙 **GitHub Intelligence:** Repository and coding profile metrics analysis.
- 📊 **Interactive Dashboard:** Gauge charts, progress indicators, and skill breakdowns.
