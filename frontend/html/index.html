How It Works

Three structured steps from raw academic & coding data to high-confidence placement.

1

Multi-Source Vector Aggregation

We ingest semester CGPA, academic attendance, active backlogs, GitHub commit velocity, and LeetCode contest ratings into a normalized 13-dimensional vector.

2

Dual-Engine ML Processing

Our pre-trained XGBoost model evaluates single-row placement likelihood in <2ms, while the Cosine Recommender matches your skill vector against 10 target roles.

3

Targeted Skill Remediation

Vector subtraction quantifies deficit gaps against your active target, outputting a prioritized timeline of phased milestones with actionable technical checklists.
