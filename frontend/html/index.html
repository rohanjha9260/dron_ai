Academic & Telemetry Profile

Ingests semester SGPA, attendance percentage, active backlogs, GitHub commits, and LeetCode problem solving metrics into a canonical 13D vector.

2

Sub-2ms ML Inference

Trained XGBoost classifier predicts placement clearing odds with TreeSHAP feature attributions, identifying exactly which factors boost your employability.

3

Cosine Career Matching

Evaluates Euclidean angular distance between your skill vector and 10 industry role vectors to recommend high-probability career paths.

4

Dynamic Learning Roadmap

Vector deficit subtraction identifies missing competencies, generating phased milestones, capstone project blueprints, and mock drills.
