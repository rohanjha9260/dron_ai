# Dron-AI Project: UI Redesign & De-AI-ification Milestone

## Project Context
Dron-AI is an engineering student career guidance and placement readiness platform. It integrates academic records, GitHub metrics, and LeetCode performance into a 13-dimensional feature vector to predict campus placement probabilities, calculate skill gaps, and provide actionable milestones.

## Milestone Objective
**Milestone**: `ui-metallic-human-craft`  
**Goal**: Eradicate all synthetic "AI-generated" visual clichés (neon glows, purple/cyan cyber palettes, floating glassmorphism, sparkle/wand emojis, and robotic buzzwords) across the entire frontend. Replace them with an authentic, human-crafted industrial design system built on **Metal Black, Shine Gray, and Tactile Shadow**.

## Guiding Aesthetics
- **Metal Black Chassis**: Matte anodized dark aluminum, milled panels, recessed wells (`#07080A` to `#1D222E`).
- **Shine Gray Specular Highlights**: 1px brushed chrome top lips, hairline mechanical seams, crisp metallic typography (`#9CA3AF` to `#F3F4F6`).
- **Tactile Shadows**: Multi-stage physical contact shadows, ambient occlusion, mechanical button depression on press (`:active { transform: translateY(1px); }`).
- **Human Engineering Copy**: Realistic campus placement context, T&P cell advisories, structured STAR interview frameworks.
